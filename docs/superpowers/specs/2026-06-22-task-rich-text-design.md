# Форматирование текста задач (TipTap, инлайн)

Дата: 2026-06-22

## Цель

Дать задачам канбана форматирование в стиле Notion: списки, буллеты, заголовки,
жирный/курсив. Ввод — через markdown-команды (`- `, `1. `, `# `, `**текст**`),
без тулбара и BubbleMenu.

## Решения

- **Форматируется сам `title`** (отдельного поля «описание» нет).
- **Ввод — markdown-инпут-правила TipTap** (StarterKit, дефолтные правила). Тулбар
  и BubbleMenu не делаем.
- **Редактирование — инлайн в карточке**, тот же контракт, что у текущего
  `InlineInput`.
- **Хранение — HTML-строка** в существующей колонке `tasks.title` (`TEXT`, лимита нет).

## Объём

В: буллет-списки, нумерованные списки, заголовки, жирный, курсив, цитата, код —
всё, что даёт StarterKit с дефолтными инпут-правилами.

Не в (YAGNI): тулбар, BubbleMenu, чек-листы `[ ]`, таблицы, картинки/файлы,
slash-меню.

## Изменения

### Зависимости (frontend)
`@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/pm`, `dompurify` (+ типы).

### Backend
Ослабить валидатор `title` с `max=200` в `models/task.go`
(`CreateTaskRequest`, `UpdateTaskRequest`) — поставить `max=10000`. Миграция не
нужна: колонка уже `TEXT`.

### Frontend
1. **`TaskEditor.tsx`** — инлайн TipTap-редактор. Контракт как у `InlineInput`:
   `defaultValue: string` (HTML), `onCommit(html: string)`, `onCancel()`.
   Коммит по blur и `Cmd/Ctrl+Enter`, отмена по `Esc`. StarterKit с дефолтными
   инпут-правилами. Плейсхолдер для пустого редактора.
2. **`KanbanWidget.tsx`** —
   - `TaskCard`: вместо `{task.title}` рендер
     `dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(task.title) }}` с
     классом `.task-content` (стили списков/заголовков/отступов).
   - Заменить `InlineInput` на `TaskEditor` в местах создания/редактирования.
3. **Календарь** (`calendar/page.tsx`) — helper `stripHtml(html): string`;
   применить там, где строится событие задачи (`title: stripHtml(t.title)`).
   Переключение «выполнено» уже шлёт сырой `task.title` — формат не теряется.
4. Стили `.task-content` (списки `list-style`, отступы заголовков) — глобальный
   CSS или модуль.

## Проверка

- Ввод `- пункт` + Enter создаёт буллет-список; `# Заголовок` — заголовок;
  `1. ` — нумерованный список; `**жирный**` — жирный.
- Карточка показывает отрендеренный HTML; вёрстка не ломается на длинном тексте.
- Календарь показывает задачу простым текстом без тегов; галочка «выполнено»
  не теряет форматирование.
